# skycast-weather
SkyCast is a modern, responsive weather forecasting web app that lets users search any city or use their location to view real-time weather conditions, 5-day forecasts, interactive map, and key details like humidity and wind speed. It supports light/dark mode, smooth transitions, and works seamlessly on both desktop and mobile devices.   
# 🌤️ SkyCast

A **modern, responsive weather forecasting website** built with **HTML, CSS, and JavaScript**.  
Fetches real-time data from [WeatherAPI](https://api.openweathermap.org) and supports **light/dark mode**.

---

## 🚀 Features
- 🌎 Search weather by city
- 📍 Detects current location
- 🌤️ Shows current & 5-day forecast
- 🌓 Light/Dark mode toggle
- 📱 Fully responsive design
- 🗺️ Embedded map with border
